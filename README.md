# BlueSend
Send files via bluetooth obex  

### Dependencies
 * python3-pyqt6  
 * bluez-obexd  
 * bluez  
 * python3-dbus  
 * python3-dbus.mainloop.pyqt6  


### Install
Open terminal and change directory to project source. Then run...  
`pip3 install --user .`  

### Uninstall
`pip3 uninstall bluesend`  

### How to send files
To send files, open a file-manager and select the files, then right click and select Bluetooth  

Or in a terminal type...  
`bluesend file1.ext file2.ext`
